A major function of any living language is the capacity to identify oneself and others, expressing names, nicknames, who one is, what they do, where they are from, and other bases of identity. Here we will explore how this works historically in the Galilean Aramaic language.


## Names & Nicknames

> **What is your name?** ⟶ {% gal "mah $:maK" %} — The appropriate [Pronominal Suffix](/chapter/possession/#pronominal-suffixes) can be added to {% gal "$:M" %} to change the subject.

> **My name is...** ⟶ {% gal "$:mI -" %} — The appropriate Pronominal Suffix can be added to {% gal "$:M" %} to change the subject.

> **I wish to be called** ⟶ {% gal "ra(UtI m:tqarE" %} — The appropriate Pronominal Suffix can be added to {% gal "ra(U" %} to change the subject.^[VR 55:3; VRV 260:1; PRK 175:6]


## Residence & Origins

> **Where are you from?** ⟶ {% gal "m:N hayyd:n ):tar )at." %}^[BR 327:8; lit. "From which place are you?"] and the Pronoun can be replaced appropriately.

> **I am from...** ⟶ {% gal "):nah m:N" %} — The Pronoun can be replaced appropriately.

> **I live in...** ⟶ {% gal "):nah yatEb b:-" %} — The appropriate form of the verb {% gal "ytb" %} ("to sit, to dwell") to change the subject and timeframe.

> **"There is a place called..."** ⟶ {% gal ")It ):tar dam:tqarE" %}^[{% gal "):tar" %} is often shortened to just {% gal "tar" %} which could be vocalized {% gal "t]ar" %}]

> **"The area around..."** ⟶ {% gal "parwwErayyah" %} or {% gal "parwwElayyah" %} (m) depending on accent.^[Both forms are attested (TN, TNGl, PT) always in the plural also in the Construct {% gal "parwwErE" %} or {% gal "parwwElE" %}.]

> **City, Town, or Village** ⟶ The irregular noun {% gal "qaryyah" %}.

> **Major City, Capitol, Province, Country** ⟶ {% gal "m:dInah" %} (f).^[{% gal "m:dInat )I+alyA)" %} = "The province of Italy" TN Num 24:24]


## Ethnicity & Race

One's race or ethnicity is usually handled using Gentillic Adjectives.


## Occupation

{% gal "bEr" %} as "one who".

- **I am a(n)...** ⟶ {% gal "):nah" %}
- **I my job/trade is...** ⟶ {% gal ")Um.anUtI -" %}

- **Builder** ⟶ {% gal "b:n)Ay" %}
- **Butcher** ⟶ {% gal "+ab.ax" %}
- **Student** ⟶ {% gal "talmId" %}
- **Teacher / Professor** ⟶ {% gal "malpaN" %}, {% gal "sapar" %}
- **Clerk / Scribe** ⟶ Also {% gal "sapar" %}, but can be combined with other words to indicate what kind, i.e.:
    - **County/City Clerk** ⟶ {% gal "sapar m:dInah" %}
    - Stretching meanings a bit: **Computer Programmer** ⟶ {% gal "sapar mag.nOn" %} or {% gal "sapar mEkanOs" %} — lit. "device scribe" ("device" from Greek).
- **Salesperson** ⟶ {% gal "m:zab.n" %} — someone who sells things. Could work for retail.
- **Shopkeeper / Tavern-keeper** ⟶ {% gal "xanwwayy" %} — someone who tends a store or restaurant, would work for waiter or waitress.
- **Mechanic** ⟶ {% gal "m:kanIq" %} (from Greek)
